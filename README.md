# 이지해 | Professional Homepage

LinkedIn 스타일의 전문가 홈페이지입니다. 경력, 역량, 교육 정보를 효과적으로 보여주는 반응형 웹사이트입니다.

## 📋 주요 기능

- **프로필 섹션**: 프로필 사진, 이름, 직급, 연락처 버튼
- **소개**: 상세한 경력 및 역량 소개
- **경력**: 직무별 경력사항 및 주요 성과
- **역량**: 6가지 핵심 역량 카드
- **교육 및 인증**: 교육 프로그램 및 자격사항
- **반응형 디자인**: 모바일, 태블릿, 데스크톱 모두 최적화
- **인터랙티브 요소**: 스크롤 애니메이션, 네비게이션 효과

## 🎨 디자인 특징

- **LinkedIn 스타일**: 전문적이고 정갈한 디자인
- **색상 체계**: 파란색 계열의 전문적인 컬러팔레트
- **타이포그래피**: 명확한 계층 구조
- **호버 효과**: 부드러운 인터랙션
- **그림자 효과**: 깊이감 있는 카드 디자인

## 📁 파일 구조

```
myhome/
├── index.html      # 메인 HTML 파일
├── styles.css      # 스타일시트
├── script.js       # 자바스크립트 기능
└── README.md       # 이 파일
```

## 🚀 사용 방법

1. 저장소를 클론하거나 다운로드합니다
2. `index.html`을 웹 브라우저에서 엽니다
3. 필요한 정보를 수정합니다:
   - 프로필 사진 URL 변경
   - 연락처 정보 입력
   - 소셜 미디어 링크 추가

## ✏️ 커스터마이징

### 개인 정보 수정
`index.html`의 다음 부분을 수정하세요:
- 프로필 사진: `<img src="..." alt="Profile Picture">`
- 이름, 직급, 위치 정보
- 연락처 및 소셜 미디어 링크

### 색상 변경
`styles.css`의 `:root` 섹션에서 색상 변수를 수정하세요:
```css
--primary-color: #0A66C2;
--secondary-color: #0D47A1;
```

## 📱 반응형 브레이크포인트

- **768px 이하**: 태블릿 화면
- **480px 이하**: 모바일 화면

## 🎯 섹션별 내용

### 프로필 헤더
- 프로필 사진
- 이름 및 직급
- 연결, 메시지, 프로필 다운로드 버튼

### 소개 섹션
- 경력 요약
- 현재 역할 및 책임
- 핵심 관심사
- 교육 경험
- 리더십 활동

### 경력 섹션
- 현재 직책: 고객가치실현팀장
- 이전 경력사항
- 각 직책별 주요 성과 및 책임

### 역량 섹션
- 6가지 핵심 역량 (카드 형식)
- 아이콘 및 설명

### 교육 섹션
- WINNEXT 회원
- WIN 토요마티네 여성리더십 프로그램
